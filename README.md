# 2Dtraj-drawer

iPad + Apple Pencilで二次元の軌跡（時系列 `(t, x, y)`）を描いて記録し、RNN学習用データセットを作るためのツール一式。

## 構成

- `index.html` — iPad Safari（Apple Pencil対応）で開く描画キャプチャアプリ。単一HTMLファイルで完結。
  - キャンバスは原点中心の正方形に固定し、キャプチャ時点で `x, y` を `[-0.9, 0.9]` に正規化（tanh飽和を避けるため）。
  - `t` は生のタイムスタンプ（未リサンプリング）のまま記録。
  - 描いたストロークは「JSONを保存」ボタンでローカルにダウンロードできる。
- `preprocess.py` — エクスポートしたJSONを読み込み、固定Hzへのリサンプリング（線形補間）とパディング+マスク生成を行い、`.npz` に変換するスクリプト。

## 使い方

1. `index.html` をこのGitHub Pages経由（または直接ファイルを開いて）iPadのSafariで開く。
2. Apple Pencilで描画し、「JSONを保存」でエクスポート。
3. `python preprocess.py <エクスポートしたjson> --hz <サンプリングレート> --out dataset.npz` で学習用データに変換。

## 設計方針の詳細

正規化・保存形式・可変長データの扱いなどの設計判断の経緯は、プロジェクト側のドキュメントにまとめてあります。
